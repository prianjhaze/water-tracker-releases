# Water Tracker

A simple, free Android app for logging your daily water intake. The whole screen is a glass that fills as you drink.

Aplikasi Android gratis untuk mencatat minum air harian. Seluruh layar adalah gelas yang terisi saat kamu minum.

**Languages / Bahasa:** English (default), Bahasa Indonesia

Ambil APK terbaru di **[halaman Releases](../../releases/latest)** (file `WaterTracker-<versi>.apk`).

## Install (sideload)

1. Open the downloaded `.apk` on your phone. / Buka file `.apk` di HP.
2. When asked, allow **Install unknown apps** for the app you opened it from (browser or Files). / Saat diminta, izinkan **Install aplikasi tidak dikenal** untuk aplikasi yang kamu pakai membukanya.
3. If Play Protect shows a warning, choose **More details > Install anyway**. The app is not distributed through Google Play, so it is "unrecognized". / Jika Play Protect memberi peringatan, pilih **Detail lainnya > Tetap instal**.
4. Updates install over the old version and keep your data. / Update menimpa versi lama dan data tetap ada.

To verify your download, compare the file's SHA-256 with the value above. / Untuk memverifikasi unduhan, cocokkan SHA-256 file dengan nilai di atas.

## Features / Fitur

- Full-screen water animation, quick amounts in a center picker (100 / 200 / 300 ml by default, editable)
- Daily target with a science-based recommendation (EFSA / NASEM reference values; a general estimate, not medical advice)
- Today's history, delete via the menu with confirmation, daily progress for the last 30 days
- Optional drink reminders
- Optional Google sign-in to keep your progress when you change devices
- English and Indonesian
